# Flex Task 1

## 📌 About the Project

Flex Task 1 is a simple web layout project created using HTML5 and CSS3. The project focuses on practicing CSS Flexbox to arrange and align webpage 
elements in a structured layout. It helped me understand how Flexbox works and how to create clean, organized web designs.

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox

## ✨ Features

* Flexbox-based layout
* Element alignment and spacing
* Organized content structure
* Simple and clean design
* Practice with CSS layout properties

## 🎯 Purpose

The main purpose of this project is to improve my understanding of CSS Flexbox and strengthen my front-end development skills.

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder in Visual Studio Code.
3. Open the `index.html` file in your web browser.
